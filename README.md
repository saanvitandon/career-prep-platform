# Placement Copilot

Placement Copilot is an AI-powered career preparation platform that helps students prepare for internships and placements through resume analysis, job description matching, interview preparation, personalized learning roadmaps, and AI-powered document assistance.

**[Try Placement Copilot here](https://ascend-ai-prep.vercel.app/dashboard)**

## Features

- **AI Resume Analyzer** — ATS-style scoring and resume improvement suggestions.
- **Resume–Job Description Matcher** — Evaluates how well a resume aligns with a job description.
- **Interview Preparation** — Generates AI-powered interview questions.
- **Personalized Learning Roadmap** — Provides a structured learning plan for career preparation.
- **PDF Question Answering** — Answers questions about uploaded documents using Retrieval-Augmented Generation (RAG).
- **AI Career Assistant** — Provides AI-powered career preparation assistance.
- **User Dashboard** — Centralized access to career preparation tools.

## Tech Stack

- **Frontend:** React.js, JavaScript, Tailwind CSS, Vite
- **Backend:** Node.js, Express.js, REST APIs
- **Database:** PostgreSQL, Supabase
- **AI:** Google Gemini API
- **Deployment:** Vercel (frontend), Render (backend), Supabase (database)
